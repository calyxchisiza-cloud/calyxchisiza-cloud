# Calyx Chisiza

I build small, tested infrastructure in Go, and software for schools, businesses, and Windows.

## Infrastructure

| Repository | What it is |
| --- | --- |
| [forgehttp](https://github.com/calyxchisiza-cloud/forgehttp) | HTTP/1.1 server with keep-alive connections and a connection console |
| [forgecache](https://github.com/calyxchisiza-cloud/forgecache) | In-memory cache with a byte limit, TTL, and a disk log |
| [forgedb](https://github.com/calyxchisiza-cloud/forgedb) | Paged storage, SQL, write-ahead logging, and a database browser |
| [forgemq](https://github.com/calyxchisiza-cloud/forgemq) | Single-process message log with disk and a topic viewer |
| [forgejobs](https://github.com/calyxchisiza-cloud/forgejobs) | Delayed and prioritised jobs with leases and retries |
| [forgesync](https://github.com/calyxchisiza-cloud/forgesync) | Offline synchronisation with last-writer-wins |
| [forgeproxy](https://github.com/calyxchisiza-cloud/forgeproxy) | Reverse proxy with longest-prefix routes and health checks |
| [forgeobserve](https://github.com/calyxchisiza-cloud/forgeobserve) | Metrics, traces, and a diagnostic log for one process |
| [forgestore](https://github.com/calyxchisiza-cloud/forgestore) | Content-addressed object store on one disk |
